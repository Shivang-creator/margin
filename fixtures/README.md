`sample-notes.md` is a page of first-year study notes on mitochondria and cellular respiration, shipped so the demo works with no notes of your own. Nothing under `fixtures/` is written by a test.
Derived from the Wikipedia articles "Mitochondrion", "Cellular respiration" and "Chemiosmosis", retrieved 2026-08-25; licence CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/), which this file also carries.
